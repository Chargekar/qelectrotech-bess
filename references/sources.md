## Expanding the corpus

Prefer official AHJ templates, public school/municipal bid sets and agency filings. For each retrieved set, record original owner/URL, download date, SHA-256, drawing date/revision, code basis, sheet IDs, status (concept/bridging/permit/bid/as-built), reuse rights, and inspection coverage. Review the full relevant sheets including notes/legends, not OCR alone. Extract semantic patterns and create original parametric assets; redistribute source artwork only with an explicit compatible license/permission. Never collect or reproduce someone else's seal/signature as an asset.
